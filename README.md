# SCT_DS_2
Titanic Dataset – Exploratory Data Analysis (EDA)

As part of my learning journey in Data Science & Business Intelligence, I performed data cleaning, transformation, and interactive dashboard creation on the Titanic dataset.

Key Highlights: Data Cleaning & Preprocessing Exploratory Data Analysis (EDA) Interactive Power BI Dashboard KPI Cards & Slicers Survival Analysis by:

Gender: Passenger Class Family Size Fare Age Groups Insights Discovered: Female passengers had higher survival rates First-class passengers survived more frequently Higher fare passengers showed better survival chances Family size influenced survival probability

Tools & Skills Used: Power BI Data Visualization Data Cleaning Dashboard Design EDA Techniques

This project helped me improve my understanding of transforming raw data into meaningful insights through visual storytelling.
